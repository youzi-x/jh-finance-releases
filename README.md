## 📖 项目简介与系统定位

**柚柚财务系统**是一款面向现代中小企业及集团分支机构的**企业级全功能多账套财务管理软件**，严格遵循财政部《企业会计准则》核心业务规范与现代化财务交互体验。

系统采用现代化 **Spring Boot 3 + Vue 3** 技术栈，通过嵌入式架构将纯净前端单页应用（SPA）与后端微核心封装为**单一自包含应用**。配套提供专用 **Windows 桌面服务管理器**与 **Windows 一键部署安装包**，无需客户自行配置复杂且繁琐的 Java/Node.js/Nginx/MySQL 环境，实现“**下载即装、双击即启、开箱即用**”。

### 🌟 核心业务功能与架构特色

1. **企业级多账套物理隔离架构**:
   - 严格遵循企业级多租户安全规范，每个账套分配独立的底层物理数据库（`fa_act_101` 等）；
   - 彻底避免传统单库多账套字段共享带来的数据串账与越权隐患，保障各公司/分支财务数据绝对安全。
2. **全流程财务核算闭环**:
   - **日常账务**: 快速凭证填制（支持快捷键与借贷自动平衡）、凭证审核、过账记账与作废整理；
   - **科目账表**: 总分类账、明细分类账、日记账、科目余额表、辅助核算余额表；
   - **资产管理**: 固定资产卡片管理、资产增减、每月折旧自动计提并无缝生成记账凭证；
   - **期末处理**: 制造费用/管理费用/销售费用自动结转、期末损益结转、结账与反结账控制；
   - **报表中心**: 自动生成资产负债表、利润表（损益表）、现金流量表，支持公式自适应校验与 Excel 导出。
3. **工业级全自动定时灾备系统**:
   - 支持多账套按日/按周/按月设置定时自动备份计划；
   - 支持保留周期自动清理、备份日志审计追踪与 `.cwbk` 专有灾备快照的一键还原。
4. **自主品牌形象与体验一致性**:
   - 全局界面、系统配置、角色权限、API 接口及通知公告已完成**全面自主品牌深度定制**，呈现纯净专业的财务软件交互体验。
5. **专有桌面运维服务管理器 (`ServiceManager.exe`)**:
   - 运行状态监控与日志查看；
   - 端口自由配置与冲突检测；
   - 一体化本地部署与独立远程数据库分离部署自由切换；
   - 国内多线路加速在线热更新。

- **操作系统**: Windows 7 SP1 / Windows 8 / Windows 10 / Windows 11 / Windows Server 2012 及以上版本（**仅支持 64 位**操作系统）

## 🖥️ 服务管理器使用说明手册

安装完成后，双击桌面的 **【柚柚财务系统服务管理器】**（或进入安装根目录运行 `ServiceManager.exe`），即可进入图形化运维控制台：

```
+-------------------------------------------------------------------------+
|                  柚柚财务系统 · 服务管理器 v1.0.0                   |
+-------------------------------------------------------------------------+
| [服务管理]  |  [端口管理]  |  [数据库配置]  |  [在线更新]  |  [关于系统] |
+-------------------------------------------------------------------------+
```

### 1. 服务管理控制台 (Service Control)
- **核心服务托管**:
  - **财务系统主服务 (Spring Boot 3 Web & API)**: 端口默认 `80`；
  - **内置 MySQL 数据库**: 端口默认 `3306`（内置自适应路径引擎）；
  - **内置 Redis 缓存**: 端口默认 `6379`。
- **操作按钮**:
  - **【一键启动全部服务】**: 依序启动 MySQL、Redis 及主应用核心，自动检测进程与端口就绪状态；
  - **【一键停止全部服务】**: 安全退出各微服务，防止非正常断电或异常终止导致数据文件损坏；
  - **【打开财务系统 Web 界面】**: 自动唤起系统默认浏览器访问财务系统首页；
- **实时日志监控**: 界面下方提供控制台实时滚动日志，可随时排查应用启动状态与异常报错。

### 2. 端口管理与冲突检测 (Port Management)
如果客户机器上已有 IIS、Apache、本地其它 MySQL 或 Redis 服务占用了默认端口，无需手动修改复杂代码配置：
1. 切换到 **【端口管理】** 标签页；
2. 自由修改目标端口（例如将 Web 端口由 `80` 修改为 `8088`，将 MySQL 端口修改为 `3307`）；
3. 点击 **【检测端口冲突】** 按钮：系统将实时扫描本地网络端口占用，并清晰提示“端口可用”或“端口被占用（附占用进程名）”；
4. 点击 **【保存端口配置】**：服务管理器将自动重写后端的 `application.yml` 与配置文件，并在提示后安全重启服务生效。

### 3. 数据库配置与分离部署模式 (Database Modes)
针对大中型企业或已有独立数据库集群的客户，系统提供**一体化/分离部署一键切换引擎**：
- **模式 A：本地一体化内置数据库（默认模式）**:
  - 使用安装包自带的便携 MySQL 实例，全自动管理启停与生命周期，单机客户首选。
- **模式 B：远程独立分离部署数据库（企业分离部署模式）**:
  1. 在【数据库配置】标签页中勾选 **“远程独立分离部署数据库”**；
  2. 填写企业现有的 MySQL 数据库连接参数：
     - **主机地址 (Host)**: 填写远程服务器 IP 或内网域名（例如 `192.168.1.200` 或 `rds.internal.company.com`）；
     - **端口 (Port)**: 数据库端口（如 `3306`）；
     - **主系统数据库名**: `ry-vue`；
     - **账套库前缀**: `fa_act_`；
     - **数据库账号与密码**: 填写具备 DDL/DML 权限的数据库用户凭据；
  3. 点击 **【测试数据库连接】**：验证网络联通性与账号授权合法性；
  4. 若远程数据库为新建空库，点击 **【一键初始化远程数据库结构与基础数据】**，系统将自动把元数据与内置科目模板导入远程库；
  5. 点击 **【保存并切换数据库配置】**，系统自动关闭本地内置 MySQL 并连接远程数据库运行。

### 4. 国内多节点在线智能热更新 (Online Update)
客户无需重新下载几百兆的安装包，即可平滑升级新版本：
1. 切换到 **【在线更新】** 标签页；
2. **加速节点选择**: 系统内置国内加速节点池（`ghproxy.net`、`gh-proxy.com` 及官方源），支持点击“测速”自动选取延迟最低的线路；
3. 点击 **【检查最新版本】**：系统从公开仓库自动拉取 `version.json`，比对当前版本与最新版本，并在界面清晰展示新版本特性与更新日志；
4. 点击 **【一键在线更新】**：
   - 系统自动经国内加速镜像下载最新的 `patch_vX.X.X.zip` 补丁包；
   - 校验文件 MD5 完整性防篡改；
   - 优雅终止主程序运行；
   - 增量热覆盖更新文件与前端资源；
   - 自动重启财务系统并完成版本升级！

## ❓ 常见问题排查与技术支持 (FAQ)

### Q1: 启动时提示“80 端口已被占用，服务启动失败”？
**解答**:
Windows 10/11 系统中，某些本地服务（例如 IIS、World Wide Web Publishing Service 或系统 SQL Server Reporting Services）可能会预先占用 80 端口。
- **解决方法**: 打开【服务管理器】-> 进入【端口管理】标签页 -> 将 Web 端口修改为 `8088` 或 `8888` -> 点击【保存端口配置】并重启服务。之后通过 `http://localhost:8088/` 即可正常访问。

### Q2: 局域网内的其它电脑如何访问本台财务服务器？
**解答**:
1. 在 Windows 防火墙中添加一条“入站规则”，放行本系统配置的 Web 端口（默认 80，或自定义的 8088）；
2. 局域网内其它办公电脑打开浏览器，直接输入财务服务器的内网 IP 地址（例如 `http://192.168.1.100:8088/`）即可实现多人协同做账。

### Q3: 工业级全自动定时备份的文件保存在哪里？
**解答**:
自动备份文件保存在系统安装目录下的 `backups\auto\` 文件夹中，文件格式为 `.cwbk`（高压缩防篡改二进制灾备快照）。系统管理员可随时在【系统管理】->【自动备份计划】页面中查看备份执行历史或进行一键恢复。
